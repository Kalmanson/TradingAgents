这套系统把现有 TradingAgents 分析能力包装成一次性付费产品：用户选择美股代码和报告语言，在 Creem 收银台付款，系统在后台生成并保存报告，再把报告链接发到付款邮箱。

## 目前能做什么

- 首页选择美股代码及 11 种报告语言。
- 单一一次性产品，价格、币种和税费方式从 Creem 读取；用户无需注册或登录。
- 通过服务端验证过的支付通知启动后台分析，浏览器跳转不能充当支付凭证。
- 报告正文同时保存到 Markdown 文件和 SQLite 数据库，并与订单关联。
- 用随机私密链接查看报告，用命令行离线查询订单、导出报告和备份数据库。
- 保存邮件发送记录，处理重复支付通知、分析失败、任务中断和邮件重试。
- 付费入口默认使用 FMP 美股日线、证券资料、基本面、财报、新闻和内部人交易，指标在本地计算；本地 CLI/Web 默认使用 yfinance。ETF 可作行情和基准，仍不能购买报告。

## 你当前可以先做的事

先在同一个 `.env` 中填写 `CREEM_TEST_*`、`CREEM_PROD_*` 两组 Creem 配置，以及共用的网站、邮件、人机验证和模型配置。只需填齐本次启动模式的 Creem 凭据；缺少必填项会直接拒绝启动并列出变量名。付费入口默认使用 FMP，另需填写 `FMP_API_KEY` 并确认接口权限；保持五个供应商选择器未设置即可让本地 CLI/Web 继续默认使用 Yahoo。显式覆盖方式见[数据源配置](付费报告部署与运行.md#34-fmp-数据源配置与回滚)，供应商不随 Creem 的测试/正式模式切换。

在当前电脑的项目目录中运行：

```sh
cd /Users/chengshuo/PycharmProjects/TradingAgents
COMMERCE_PUBLIC_URL=http://localhost:8000 \
.venv/bin/tradingagents-mvp serve --mode test
```

然后打开 [本地首页](http://localhost:8000)。正式环境使用 `serve --mode prod` 并配置 HTTPS 网站地址；不传 `--mode` 时读取 `CREEM_MODE`，缺省为 `test`。按 `Ctrl+C` 停止。若是新机器或尚未安装依赖，先按[部署与运行文档](付费报告部署与运行.md)完成安装。

代码已完成本地验证；真实支付、真实模型运行和邮件收件的完整联调仍需使用你实际配置的服务完成。本地测试通过，不代表域名、商户账户或发信域名已配置成功。

FMP 真实接口烟测仍需具有相应权限的 Key；缺少 Key 时付费网站不能通过股票资格校验。Marketstack 可继续通过配置用于行情和资料。FMP 数据商业展示授权与 SDK 代码许可不同，正式售卖前需按实际合同确认。
