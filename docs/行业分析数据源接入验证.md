**SEC 官方请求规范复核（同日补充）**

对于持续的 Access Denied，FAQ 给出的处理方式是将错误文本或截图及出口 IP 提供给 webmaster@sec.gov。请求格式合规不等于一定解除网络或访问限制。

**流程、故障与兼容回归**

普通股票默认五位分析师，行业节点在基本面之后、多空辩论之前。报告进入多空研究员、三位风控分析师及研究/最终决策经理的上下文，CLI、本地网页、独立 `1_analysts/industry.md` 和完整报告均接入。新付费订单保存 `industry_sources`、`industry_max_related_companies`；旧任务显式保存的分析师列表不追加角色。身份识别后的有效角色集统一用于进度、执行和检查点。

SEC 优先读取 `SEC_USER_AGENT`，否则复用本项目已授权的客服邮箱。邮箱和 API Key 不写入订单、报告或请求日志。限速为单进程共享每秒一次，当前单进程部署适用；如果将来多进程部署，需要增加跨进程限速。403/429 停止本轮该来源的后续网络请求，已有有效缓存仍可读取；超时/5xx 最多重试一次。索引缓存一小时，当前文件六小时，accession 原文长期保存；使用现有运行/订单隔离缓存目录。
